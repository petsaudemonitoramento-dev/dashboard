1) Pare o servidor com Ctrl+C.
2) Extraia e copie tudo para C:\dashboard2_0.
3) Aceite substituir os arquivos.
4) Execute:
   cd C:\dashboard2_0
   npm install lucide-react @supabase/supabase-js @supabase/ssr
   npm run dev
5) Abra http://localhost:3000

Rotas: /login, /cadastro, /recuperar-senha, /dashboard.
